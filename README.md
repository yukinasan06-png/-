# 配信カウンター & 盛り上がりメーター & ルーレット

YouTube 配信向けのカウンター／盛り上がりメーター／ルーレットツールです。
Node.js だけで動きます（追加インストール不要）。

## 設置

1. ダウンロードした zip を右クリック →「プロパティ」→ 下の「許可する」にチェック →「OK」
   （これをしないと Windows に start.bat をブロックされることがあります）
2. zip を展開し、中の `haishin-counter` フォルダを今のツールのフォルダ（例：`わんコメ自作カウンター`）の中に置く
   - 今のツール（ポート 8787）とは別フォルダ・別ポート（8790）なので、同時に起動できます

## 起動

1. `haishin-counter` フォルダの `start.bat` をダブルクリック
2. ブラウザで操作パネル（http://localhost:8790/ ）が開きます
3. OBS に「ブラウザ」ソースを追加し、操作パネルの「OBS用URL」タブのURLを貼り付けます

| オーバーレイ | URL |
|---|---|
| カウンター | http://localhost:8790/overlay/counter.html |
| 盛り上がりメーター | http://localhost:8790/overlay/meter.html |
| ルーレット | http://localhost:8790/overlay/roulette.html |

設定・カウント・テンプレは `data.json` に自動保存されます。

**わんコメ・YouTube の自動カウントは、操作パネルか OBS の画面（カウンター／メーター／ルーレット）のどれかが開いている間に行われます。**
（サーバーは外部に接続せず、ブラウザ側がわんコメ・YouTube から受け取ってサーバーへ送る仕組みです。複数開いていても二重にはカウントされません）

## 1. カウンター

| 項目 | 取得元 |
|---|---|
| 同接 | YouTube Data API（またはわんコメの配信情報）。現在値と最高値を表示 |
| 高評価 | YouTube Data API（またはわんコメの配信情報） |
| スパチャ（回数・金額） | わんコメ |
| 初見コメント | わんコメ（`isFirstTime`） |
| コメント数 | わんコメ |
| メンギフ | YouTube Data API（またはわんコメのコメントから判定） |
| 特定の言葉 | わんコメ（登録した言葉を含むコメントを数える） |
| カスタム1〜10 | 手動（任意で「反応ワード」を登録するとコメントからも自動加算） |

- 自動の項目も ± ボタンで手動修正できます
- カスタム項目は「＋ カスタム項目を追加」で最大10個まで追加
- 操作パネル上でキーボードの `1`〜`0` でカスタム1〜10 を +1（`Shift` で −1）

### わんコメ連携
わんコメを起動しておけば自動で接続します（`127.0.0.1:11180`）。
配信者本人のコメントは初期設定では数えません。

### YouTube 連携（同接・高評価・メンギフ）
1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成し「YouTube Data API v3」を有効化
2. 「認証情報」→「APIキー」を作成
3. 操作パネル「接続設定」タブに APIキー と 配信URL（または動画ID）を入力して保存

配信URLを空欄にしてチャンネルID（`UC...`）を入れると、配信中のライブを自動で探します。

**API の使用量について**：無料枠は 1日 10,000 ユニットです。
高評価（30秒間隔）で約120/時、メンギフ取得のためのチャット取得（15秒間隔）で約1,200/時を使います。
長時間配信する場合はチャットの取得間隔を長くするか、メンギフの取得元を「わんコメ」にしてください。

## 2. 盛り上がりメーター

- 各項目の「pt / 回」の合計がメーターに溜まります（スパチャは「100円あたり」のポイントも設定可）
- 同接は増減するため「最高同接 × pt」で加算します（初期値 0pt）
- 「満タンになるポイント」ごとにメーターが満タン → ルーレットが自動で回ります
- 一度に複数回分満タンになった場合は、ルーレットが順番に回ります（待機数を表示）

## 3. ルーレット

- テンプレートは30個。★ が付いているテンプレが使われます（「★ このテンプレを使う」またはダブルクリックで切り替え）
- 項目はテキスト欄に 1行1項目で入力（Excel などから貼り付けて一括入力できます）
- 🔀 シャッフルで並び順を入れ替え。「毎回シャッフル」をONにすると回すたびに並びが変わります
- 「一括インポート」で30個のテンプレをまとめて入力できます：

```
## 罰ゲーム
歌う
モノマネ
## ご褒美
好きなお菓子
スタンプ作成
```

- 同じ項目を複数行入れるとその項目が当たりやすくなります
- `http://localhost:8790/api/spin` を開くとルーレットが回ります（Stream Deck などから利用可）

## 動作テスト

操作パネルの「テスト」タブで、コメント・スパチャ・メンギフ・高評価を疑似的に発生させて動きを確認できます。
確認後は「全カウンターをリセット」してください。
