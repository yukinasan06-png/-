ルーレット設定

履歴

    わんコメ連携

    コメント数・初見コメント・スパチャ・特定の言葉・カスタム項目の反応ワードは、わんコメから取得します。わんコメを起動しておけば自動で接続します（初期ポート 11180）。

    YouTube 連携（高評価・メンギフ）

    高評価数とメンバーシップギフトは YouTube Data API v3 から直接取得します。Google Cloud Console で API キーを作成し（YouTube Data API v3 を有効化）、下に入力してください。
    配信URLを空にしてチャンネルIDを入れると、配信中のライブを自動検索します（検索は1回100ユニット消費）。

    API の1日の上限（初期 10,000 ユニット）の目安：高評価30秒間隔 ≒ 120/時、チャット15秒間隔 ≒ 1,200/時。長時間配信ではチャット間隔を長めにしてください。

    取得元の切り替え

    OBS ブラウザソース用URL

    OBS の「ソース」→「ブラウザ」で下のURLを貼り付けてください。背景は透明です。

    カスタマイズ（URLの後ろに付けるパラメータ）

    • カウンター：?ids=likes,superchat,custom1 表示する項目を指定（未指定なら「OBS表示」がONの項目）／ &layout=row 横並び ／ &scale=1.5 拡大 ／ &amount=0 スパチャ金額を隠す
    • メーター：?scale=1.5 拡大 ／ &numbers=0 数値を隠す ／ &vertical=1 縦メーター
    • ルーレット：?size=600 円の大きさ(px) ／ &sound=0 効果音なし

    項目ID：likes（高評価）, superchat（スパチャ）, first（初見）, comments（コメント数）, gift（メンギフ）, keyword（特定の言葉）, custom1〜custom10

    外部ツール（Stream Deck など）から操作：/api/spin でルーレット、/api/add?id=custom1&n=1 で加算。

    動作テスト

    配信せずにカウンター・メーター・ルーレットの動きを確認できます（実際のカウントに加算されます。確認後はリセットしてください）。
